# ApexPlanet Internship — Task 1 Browser Alternative

## Project title
Onboarding and Environment Setup

## Purpose
This lightweight, mobile-friendly web page is a browser-based learning aid for organizing Task 1 activities. It includes a 9-day outline, a setup checklist, official learning links, and a reflection field.

## Files
- `firstindex.html` — page structure
- `firststyle.css` — responsive styling
- `firstscript.js` — checklist progress and copy-reflection interaction
- `environment-setup.md` — fill-in activity log

## How to run
1. Download or clone this repository.
2. Open `firstindex.html` in a modern browser.
3. Use the checklist and resource links.
4. Record your actual learning and testing in `environment-setup.md`.

No build step or local software installation is required to view this web prototype.

## Important scope note
This is a browser-based alternative/prototype. It does not install Android Studio, configure the Android SDK, or constitute a native Android application. If the internship mentor requires Android Studio setup specifically, ask whether this alternative is acceptable.
