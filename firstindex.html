LEARNING PLAN

Days 1–2

Onboarding

Read the task brief, understand the expected deliverables, and plan your work.

Days 3–5

Environment exploration

Learn what Android Studio, Android SDK, Java/Kotlin, Gradle, Git, and GitHub are used for. If avoiding installation, document that you used a browser-based alternative.

Days 6–9

Android fundamentals

Study Activities, Fragments, layouts, and basic app flow. Build a small prototype using an online tool and record what you learned.
